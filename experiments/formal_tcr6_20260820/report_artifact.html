TCR-Specific Loss 消融实验

核心问题

在 A6 scaffold 固定、仅重设计 CDR3 的条件下，显式引入 TCR-specific 的约束，能否把设计出的 CDR3 推向更接近天然 TCR repertoire 的序列空间，同时不牺牲结构与 interface 质量？

HLA-A*0201 · 3 peptides × α/β = 6 cases 2×2 ablation · 24/24 jobs · 0 failed seed 42 · CDR3-only backbone 7bf6251
通道一 · 直接作用于序列空间

TCR sequence prior

用 TCRLM（在天然 TCR repertoire 上训练）对 CDR3 打分，把「像不像真实 TCR」变成一个可优化的量。

soft prior → proposal gradient
hard prior → verifier / MCTS tree value
通道二 · 通过相互作用模式间接约束

TCR contact loss

奖励 CDR3 真正接触 peptide、惩罚 framework 介导的 pMHC 结合，防止设计退化成泛化的 MHC binder。

contact grad → proposal gradient
hard contact → verifier / MCTS tree value

01实验设计

两条通道各自独立开关，2×2 四个 arm

两条通道刻意做成可分别 ablate 的独立信号，注入位置也完全对称（proposal 梯度 + verifier/MCTS 两条路径）。所有 arm 共用同一 scaffold、同一 seed、同一 search budget。

评估上有一条硬性纪律：全部 arm 由同一个 verifier、同一个固定 eval seed 重新打分，contact 指标对没有优化过它的 arm 也照样计算。因此下面没有任何一列依赖 arm-specific 的 total_loss——这正是上一轮 Protenix 分析被污染的地方。

02主结论

序列先验成立：CDR3 确实被推向了天然 TCR 空间

这是对核心问题的正面回答。TCRLM prior 让 CDR3 的 repertoire typicality 显著提升（−0.69 nats，5/6 case），而且结构质量同时变好（5/6）——没有 trade-off。

更直观的看法是把设计序列和天然 A6 自身的 CDR3 放在同一把尺子上：

接触约束不成立：达成了指标，毁掉了目的

通道二的结果相反。CDR3–peptide 接触确实上去了（5/6），但结构变差（5/6），而且 r_pep——CDR3 接触在总 TCR–pMHC 接触中的占比——反而下降。也就是说它正在制造它本该阻止的那种泛化 MHC binder。

04改法

三个机制，三个对应的改动

左右严格一一对应。其中 02 是根本性的，01 和 03 是补丁——只做一件事的话，做 02。

机制 01

梯度反向

接触梯度 77% 的步骤与结构梯度夹角为负，均值 −0.348，在系统性对抗结构优化。

改法 01 · 补丁

梯度投影（PCGrad 式）

混合前把接触梯度中与结构梯度反向的分量投影掉，只保留正交/同向部分。每步一次点积，几乎免费。退一步的做法是把 λ_contact 从 0.1 降到 0.03。

机制 02

目标函数只约束分子

降低 contact_nll(CDR3,pep) 最省力的路径是把整个复合物压紧，因为分母 Contact(TCR,pMHC) 根本不在目标里。

改法 02 · 根本

优化 r_pep 对天然值的偏离

L = (r_pep − r_natural)²，目标是匹配天然值而非最大化。比值天然免疫「整体压紧」：分子分母同涨，比值不动。已实现并验证。

机制 03

framework 惩罚力度不足

hinge 在搜索中触发 75.8%（591/780），并非失效，但只占目标函数 ~12%，拦不住 0.58 的净漂移。

改法 03 · 补丁

加大 λ_FW

提高 framework 项权重而非抬高阈值。若采用 02 的比值形式，则不再需要阈值。

一个额外的好消息

cos(contact, tcr_prior) = 0.000（arm C）/ −0.008（arm D）。两条通道在梯度空间里几乎完全正交。

这正是当初把它们设计成可分别 ablate 时想要的性质，也解释了 arm D 的效果大致等于 B 与 C 的叠加。所以接触约束的问题出在目标函数的形式上，不在它与序列先验的耦合上——改 02 就够，不需要重构整条通路。

改法 02 已实现并验证：梯度符号翻转了

能说的：符号一致的两条——TCRLM prior 提升 CDR3 的 repertoire typicality（5/6）、接触约束提高 CDR3–peptide 接触（5/6）。加上梯度诊断，失效机制是被直接测量到的，不是推测。

不能说的：

  • 只有 1 个 seed。结构那几个 delta（±0.04~0.09）小到一个 seed 分不开 run-to-run variance，要下结论得补 seed 43 / 44。
  • ESM-C NLL 每个 arm 都是 3/6，纯抛硬币——没有任何 arm 改善了通用蛋白 naturalness。
  • self-scoring 问题。TCRLM prior 让 TCRLM NLL 变好，但 ESM-C NLL 没动，这与上一轮 Protenix audit 抓到的是同一个模式。所以对核心问题的正确表述是「推向了 TCR repertoire 的典型区域」，而不是笼统的「更 natural」。建议汇报时主动先说这一点。
