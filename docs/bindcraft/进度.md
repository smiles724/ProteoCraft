## 2026-03-12

### Loss 体系替换

- 将原先的自定义几何 loss 替换为原版 BindCraft 风格的 loss 体系。
- 移除旧项：`attraction`、`clash`、`intra_clash`、`compactness`
- 接入新项：`pLDDT`、`pAE(intra)`、`i_pAE(inter)`、`con`、`i_con`、`iPTM`、`Rg`、`helix`
- 默认权重对齐原版 BindCraft `default_4stage_multimer.json`

### 完成方式

- 以 `BindCraft_original/functions/colabdesign_utils.py` 和 ColabDesign 的 `af/loss.py` 为基准，逐项对照当前实现。
- 重写 `confidence.py`，重新实现 `pLDDT`、`pAE / i_pAE`、`con / i_con`、`iPTM`
- 重写 `geometry.py`，实现动态 `Rg` 与 `helix`
- 修改 `pipeline.py`，统一接入新的 loss 计算逻辑与默认权重
- 提交 SLURM 测试任务，检查各项 loss 是否正常输出，并验证 total loss 是否能够下降

### 修复的问题

- `pAE / i_pAE` 未做归一化与对称化，导致数值过大、主导总 loss
- `con / i_con` 之前使用了近似公式，不能正确反映原版 BindCraft 的 contact loss
- `helix` 的公式与原版不一致，量纲和梯度方向存在偏差
- `Rg` 的统计对象不对，之前按全部 binder 原子计算，现改为按代表原子计算
- binder 链与 atom mask 的判断逻辑依赖顺序，存在潜在错误，现改为按 `asym_id` 映射

### 验证结果

- 验证任务：SLURM Job `9573213`
- 修复后，新 loss 体系已可稳定运行
- 所有 8 个 loss 项都能正常输出，且数值范围更合理
- total loss 不再像修复前那样持续升高，而是能够明显下降
- 本次测试中，最佳结果出现在 `step 40`，`total loss` 从 `6.69` 下降到 `2.70`
- `pLDDT` 和 `iPTM` 也出现了同步改善，说明优化方向基本正确

### 当前结论

- 今天的主要目标“完成 loss 体系替换并验证其可用性”已经完成。
- 当前代码层面没有发现阻断性的 loss 实现 bug，后续重点将转向收敛深度、训练步数、学习率和动态 tau 调度等优化问题。

### 梯度引导离散候选 + 混合优化循环（阶段二）

- 目标：将纯一阶 Adam 更新模式升级为"一阶梯度提议离散突变 → 零阶全链路验证 → 贪心接受"的混合优化循环

### 完成内容

- 新建 `bindcraft/hallucination/mutation_proposer.py`：梯度引导的离散候选生成器
  - 从梯度矩阵 G 计算突变收益矩阵 `Delta_L[i, c→a] = G[i,a] - G[i,c]`
  - 选取 Top-K 候选突变，按 `Softmax(-Delta_L / T_sample)` 采样组合出 B 条离散候选序列
- 在 `pipeline.py` 中新增 `run_hybrid_hallucination()`，实现四步混合循环：
  1. 一阶反传：STE → 单步外推 → loss → backward → Adam 更新（保留动量）
  2. 候选生成：从 `theta.grad` 提取突变潜力，采样 B 条离散序列
  3. 零阶验证：对 B 条候选调用 `zeroth_order_eval()` 做完整 AF3 推断
  4. 贪心接受：最优候选若优于当前最佳则更新序列，并同步 theta
- 将 `DEFAULT_LOSS_WEIGHTS` / `DEFAULT_CONTACT_PARAMS` 从 `pipeline.py` 迁移至 `utils.py`，解决 `pipeline ↔ zeroth_order` 的循环导入
- 新建 `scripts/test_hybrid.py` 验证脚本，含日志持久化

### 验证结果

- mutation_proposer 单元测试：序列转换、突变收益矩阵、Top-K 选取、候选采样均正确
- 混合循环集成测试（3 轮 × 4 候选，Target=21aa, Binder=40aa）：

## 算法深化：四项未完成内容

> 以下内容对应 `Bindcraft v2零阶更新.md` 和 `BindcraftV2算法结构.md` 中的设计规划，当前代码尚未实现。

### 1. 先验约束掩码（M_prior）

- **目标**：在候选突变采样中引入生物物理先验，使突变方向更贴近真实演化路径，而非纯梯度驱动。
- **做法**：对每条分支，从梯度矩阵计算突变收益矩阵 $\Delta_L[i, c\to a]$ 后，再乘以 BLOSUM62 替换矩阵或 ESM 语言模型的位置特异性打分，得到加权后的收益排名，据此选取 Top-K 候选突变。
- **意义**：避免不合理氨基酸替换（如 Cys→Pro 在螺旋中破坏氢键骨架），提升候选序列的生物物理可行性。

### 2. Beam Search 多分支演化

- **目标**：将单路径贪心搜索升级为多种群并行探索，提升隐式回退能力。
- **做法**：维护 beam width = B 条独立序列分支；每轮迭代中，每条分支各自独立计算一阶梯度并产生 K 条候选突变，共生成 B×K 条候选序列；零阶验证全部候选后，全局排序保留前 B 条进入下一代。
- **关键公式**：$\{A_{t+1}^{(1\dots B)}\} \leftarrow \text{Top}_B\left(\{A_{\text{cand}}^{(m)}\}_{m=1}^{B \times K}\right)$
- **注意**：当前实现中 `B_candidates=8` 对应的是**每条分支的候选数 K**，而真正的 beam width B=1（只有一条演化路径），尚未完整实现 B≥2 的多分支架构。

### 3. 多频段 τ 融合

- **目标**：同时兼顾宏观结构探索（粗粒度）与局部细节精修（细粒度）。
- **做法**：在每个优化步中，同时用一个大 $\tau$（如 $\tau=0.8$）和一个小子（如 $\tau=0.05$）各做一次一阶前向，分别得到梯度 $G_{coarse}$ 和 $G_{fine}$，按固定比例 $\alpha$ 加权融合：$G = \alpha \cdot G_{coarse} + (1-\alpha) \cdot G_{fine}$，再据此生成候选突变。
- **意义**：避免单一 τ 值在"探索"与"精修"之间的trade-off。

### 4. 宏观呼吸机制

- **目标**：当混合优化陷入局部最优时，主动跳出。
- **做法**：在 `TauScheduler` 中新增停滞检测逻辑：若连续 $P$ 步零阶 loss 均未下降，则将 $\tau$ 回退至宏观拓扑阶段上限（如 $\tau\approx 0.9$），同时临时降低 `con/i_con` 权重以放宽接触约束，允许骨架做大幅拓扑调整；待 loss 重新下降后恢复正常调度。
- **意义**：在模拟退火（Step 4 接受准则）的基础上，额外增加"主动回退搜索方向"的能力，形成双保险。
